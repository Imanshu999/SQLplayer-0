# SQLplayer-0

Android APK build repository.

Use **GitHub Actions -> Build Android APK -> Run workflow**.

The workflow restores the required `maxrave-dev/core` `multiplatform` source, installs Java 17 and Android SDK, builds the Android APK, and uploads it as the **SQLplayer-APK** artifact.

See [APK_BUILD_GUIDE.md](APK_BUILD_GUIDE.md) for local build and customization instructions.
